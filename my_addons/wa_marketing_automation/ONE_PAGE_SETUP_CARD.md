### ⏰ HOUR 3: REPORTS SETUP
```
SAVE THESE FILTERS:
1. Sales → Reporting → Sales
   □ Group by: Category → Team
   □ Save as: "Monthly Sales by Source"

2. WhatsApp → Reports → Demographics  
   □ Group by: Age Group → Tier
   □ Save as: "Customer by Generation"

3. Sales → Reporting → Sales
   □ Sort: Revenue ↓ Limit: 20
   □ Save as: "Top 20 Products"
```

## 🆘 TROUBLESHOOTING

**"Can't see categories"**
→ Settings → Users → Edit → Technical: Show Full Menus ✓

**"Reports empty"**
→ Check date filter (This Month vs All Time)

**"Wrong totals"**
→ Check: Tax Included? Status = Confirmed?

**"Missing customers"**
→ Check: Is Customer = Yes, Active = Yes
